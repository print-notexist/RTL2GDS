# RTL2GDS OpenLane Documentation

This repository contains the documentation, screenshots, reports, observations and debugging logs from the RTL2GDS OpenLane learning flow.

The repository has been divided week-wise for easier navigation.

## Important Note

The folders contain the readmes for the progress of those sections specifically.

- Week1 contains separate `.md` files for each of the 5 days individually.
- The remaining weeks contain one consolidated `.md` file for that week's work.

Please navigate into the respective week's folder and open the corresponding markdown file(s) to view:
- Progress
- Explanations
- Screenshots
- Reports
- Runtime observations
- Debugging steps
- Toolchain understanding
